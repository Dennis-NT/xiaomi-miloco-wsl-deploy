# 5 分钟快速部署版

## 1. 适用前提

- 你使用的是 `Windows + WSL Ubuntu 24.04`
- 摄像机和电脑在同一局域网
- 当前项目目录已经是这次修补后的版本
- 你准备直接从这个项目目录重新部署


## 2. Windows 先做这几件事

### 2.1 确认 `C:\Users\<YourUser>\.wslconfig`

```ini
[wsl2]
networkingMode=mirrored
dnsTunneling=false
firewall=true
autoProxy=false
```

### 2.2 管理员 PowerShell 放行 Hyper-V 防火墙

```powershell
Set-NetFirewallProfile -Profile Domain,Private,Public -Enabled True
Set-NetFirewallHyperVVMSetting -Name '{40E0AC32-46A5-438A-A0B2-2B479E8F2E90}' -DefaultInboundAction Allow
Set-NetFirewallHyperVVMSetting -Name '{40E0AC32-46A5-438A-A0B2-2B479E8F2E90}' -DefaultOutboundAction Allow
New-NetFirewallHyperVRule -Name 'WSL-HyperV-Allow-In' -DisplayName 'WSL HyperV Allow In' -Direction Inbound -VMCreatorId '{40E0AC32-46A5-438A-A0B2-2B479E8F2E90}' -Protocol Any -Action Allow
New-NetFirewallHyperVRule -Name 'WSL-HyperV-Allow-Out' -DisplayName 'WSL HyperV Allow Out' -Direction Outbound -VMCreatorId '{40E0AC32-46A5-438A-A0B2-2B479E8F2E90}' -Protocol Any -Action Allow
wsl --shutdown
```

### 2.3 Docker Desktop

- 关闭 `Ubuntu-24.04` 的 WSL Integration
- 退出 `Docker Desktop`


## 3. Ubuntu 执行

进入项目目录：

```bash
cd <repo-root>
```

如果还没装 WSL 原生 Docker：

```bash
bash ./setup-native-docker.sh
```

重新打开 Ubuntu 终端后确认：

```bash
docker context ls
docker version
docker compose version
ip addr
```

预期：

- `docker context ls` 当前是 `default *`
- `ip addr` 里有 `192.168.1.x`


## 4. 部署命令

```bash
cd <repo-root>
docker compose build miloco
docker compose up -d
docker compose ps
docker compose logs --tail 40 micam1
curl -kI https://localhost:8000/login
```

正常时日志里应看到：

- `Login successful`
- `WebSocket connected. Streaming data...`
- `Keyframe detected! Starting stream...`


## 5. 访问地址

- 本机 Windows：`https://localhost:8000`
- 其他局域网电脑：`https://<Windows-LAN-IP>:8000`
- go2rtc：`http://<Windows-LAN-IP>:1984`


## 6. 关键配置不要改错

`.env` 里至少要保证：

```env
MILOCO_BASE_URL=https://localhost:8000
CAMERA_ID=1234567890
RTSP_URL=rtsp://localhost:8554/your_stream1
VIDEO_CODEC=hevc
MIOT_LAN_TARGETS=192.168.1.50
```


## 7. 最常见问题

### 7.1 页面显示“设备已离线”

先检查：

- Docker Desktop 有没有误开并接管 Ubuntu
- WSL 是否还是 `mirrored`
- Windows / Hyper-V 防火墙规则是否生效

### 7.2 本机访问 `<Windows-LAN-IP>:8000` 不正常

直接改用：

`https://localhost:8000`

### 7.3 Edge 解码失败

优先改用 `Chrome`。

### 7.4 放大画面只显示一半

当前项目已经修补。

如果仍看到旧效果：

- `Ctrl + F5`
- 或开无痕窗口重新访问
