# 公开发布前检查清单

在把这个目录推到 GitHub 前，建议按这份清单过一遍。

## 1. 不要提交这些运行态文件

- `.env`
- `miloco/miloco.db`
- `miloco/cert/*`
- `miloco/log/*`
- `miloco/miot_cache/*`

它们已经被 `.gitignore` 忽略，但如果你之前手动强制添加过，仍要先移出暂存区。

## 2. 新仓库第一次提交前建议执行

```bash
git init
git status --ignored
```

确认上面那几类敏感文件都显示为 ignored，而不是 staged。

## 3. 建议首批提交的文件

- `README.md`
- `NOTICE.md`
- `.gitignore`
- `.env.example`
- `docker-compose.yml`
- `Dockerfile`
- `Dockerfile.miloco`
- `setup-native-docker.sh`
- `docs/`
- `go2rtc/go2rtc.yaml`
- `micam/`

## 4. 发布前再看一眼的内容

- README 里有没有残留你自己的局域网 IP
- 文档里有没有残留你的账号、密码 md5 或设备 DID
- 是否明确说明了这是基于上游项目的部署增强版
- 是否已经说明 `Docker Desktop` 不应接管该 WSL 发行版

## 5. 推荐仓库描述

可以直接用这一类描述：

`A deployment-focused Windows WSL distribution for Xiaomi Miloco + Micam + go2rtc with native Docker and documented fixes.`
